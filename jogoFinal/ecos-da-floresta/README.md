# Ecos da Floresta

Projeto final da trilha de desenvolvimento de jogos utilizando Kaplay.

## Pastas

- `assets/personagem/`: sprites da protagonista
- `assets/inimigos/curupira/`: sprites do Curupira
- `assets/background/`: fundos e cenário
- `assets/plataformas/`: chão e plataformas
- `assets/objetos/`: objetos do cenário e interação
- `assets/sounds/musicas/`: músicas
- `assets/sounds/efeitos/`: efeitos sonoros
- `src/main.js`: código principal do jogo

## Executar

```bash
npm install
npm run dev
```

Novas estruturas serão adicionadas apenas quando forem necessárias durante o desenvolvimento.
